# Microcopy — Civic Aura's voice

Rule: the *system underneath* (Aura math, moderation, duplicate detection) is always serious and
reliable. Only the *words shown to the user* carry the Gen-Z tone. Never let the tone make the
actual rule unclear — always pair slang with the real number/fact.

| Event | Message |
|---|---|
| Positive report approved | "W report 🔥 +1 Aura for [Locality]" |
| Negative report approved | "Nah bro… that's an L 💀 −1 Aura for [Locality]" |
| Report rejected by AI (photo doesn't match) | "That ain't it chief 😭 photo doesn't match the category — try again" |
| Duplicate report | "Already flagged today 👀 someone beat you to it — check back after 24h" |
| Locality trending up (big recent gain) | "[Locality] is cooking 🔥🔥" |
| Locality trending down | "[Locality] is not it right now 💀" |
| Locality hits a new high | "[Locality] just hit a new high — [Aura] Aura. Unmatched." |
| Challenge started | "New challenge dropped for [Locality]: [goal]. Let's get it." |
| Challenge completed | "CHALLENGE COMPLETE ✅ [Locality] locked in and delivered" |
| Challenge failed (deadline passed) | "Challenge missed 😬 run it back next week" |
| Empty state (no reports yet in an area) | "Nobody's reported here yet — be the first to set the vibe" |
| User's report is pending AI review | "Checking your evidence… hold up 👀" |

## Guardrails
- Never use slang that could read as mocking a real hardship (e.g. don't joke about serious
  environmental damage or public safety incidents — keep the L/W language for everyday litter,
  parking, noise-level stuff).
- Keep it readable for non-native English speakers too — pair emoji/slang with a clear number
  ("+1 Aura") every time, never slang alone.
- No slang aimed at a specific person — always about the *locality*, never "you're trash," always
  "that's an L for [Locality]."
